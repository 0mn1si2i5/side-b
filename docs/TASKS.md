# 开发任务

## 当前阶段目标

当前阶段进入 Song 展示阶段，在现有 Rooms 主路径基础上补可复用的歌曲展示组件。

后续 coding mode 应遵守：

- 每次只完成一个最小任务
- 每次最多修改 1-3 个文件
- 始终保持工程可编译
- 先模型，后 mock，后页面，后交互
- 先打通主路径，再补细节

---

## 当前原则

- 所有功能先基于 mock data 实现
- 暂不接入真实 Spotify / 网易云 / Apple Music / QQ 音乐 API
- 暂不实现真实播放能力
- 暂不实现登录、鉴权、后端同步
- 不引入第三方 UI 库
- 不修改 `project.pbxproj`，除非明确要求
- View 不写复杂业务逻辑
- 新增内容必须能被下一轮复用，不做一次性临时堆叠

---

## 当前不做

- 真实平台 API 接入
- 真实深链跳转
- 站内播放
- 登录与用户体系
- 云端同步
- 截图识别
- 复杂状态管理
- 推荐、社区、评论等扩展功能
